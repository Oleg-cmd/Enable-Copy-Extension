OCR Settings (Text Extraction)

How to add more languages:
  1. Go to the Tesseract Data Repository.
  2. Find the file for your language (e.g., fra.traineddata.gz for French).
  3. Download it to your computer.
  4. Click "Browse..." below and select the downloaded file.

Note: English (eng) is already included by default.

Active Languages for OCR:

Select which languages Tesseract should use when extracting text. You can enable multiple languages at once for better recognition. English is built-in and always available.
